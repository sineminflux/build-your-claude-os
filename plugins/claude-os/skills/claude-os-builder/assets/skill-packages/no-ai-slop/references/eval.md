# No-Slop Final Pass (eval)

Run this after the copy is written or edited, before delivering. A separate step, never merged into drafting; flow-reading hides triads, colon frames, and stealth adverbs. Answer each check pass or fail. If any check fails, fix the draft and run the checks again.

## The brake (run first)

1. Did you confirm each flagged line is actually slop before cutting it? A line carrying voice, a real opinion, a concrete detail, or characteristic rhythm stays, even if it trips a category.
2. Is every fix the smallest change that clears the tell, with no strong human sentence rewritten for tidiness?

## High-frequency tells

Scan the WHOLE text per check, not a sample.

3. Em dashes: counted, and 0 in generated copy? (The writer's own em dashes in their essays stay.)
4. "It's not X, it's Y" pivots: none? Test: delete the negation; if the second sentence still reads true, the negation was a false runway, so cut it.
5. Dramatic staccato / rule of three: no run of three short parallel beats ("Same machine. Different trainer. Different personality.")? Folded into real sentences?
6. Throat-clearing / false-importance frames: no "The thing is," "What matters is," "The truth is," "Here's what..." openers? "Here is" kept only when concrete content (an example, quote, or list) follows.
7. Colon-label constructions: no "Label: explanation" openers?
8. Empty-emphasis tags: no "that's the whole point," "changes everything," "that is the mistake"?
9. Stealth adverbs: quietly, gently, softly, simply, just, merely, slowly, casually all deleted unless load-bearing?

## Full sweep

10. Did you go category by category through all of references/kill-list.md, not only the high-frequency tells above?
11. One instance means more: for every pattern caught once, did you re-scan the whole text for it? They cluster.
12. Scan the whole file, including code: JS/TS string literals, prompt or instruction text, alt text, ARIA labels, and code comments checked too? ("X, not Y" hides there most.)

## Delivery

13. Substantial deliverable (essay, post, newsletter, doc, saved file, or copy over ~150 words): short report attached, one line per category, each marked CLEAN or with the exact fix, ending on the em-dash count?
14. Short chat copy (under ~150 words): scan run and fixed silently, flagged only if a fix needed a judgment call?

Report format (substantial deliverables):

```
No-slop final pass:
- Em dashes: 0
- "It's not X, it's Y" pivots: clean
- Dramatic staccato / triads: fixed 1 ("Same machine. Different trainer..." -> one sentence)
- Throat-clearing frames: fixed 2 ("Here is the part that breaks the spell", "Here is the part that matters")
- Stealth adverbs: fixed 1 ("quietly compacts" -> "compacts")
- Empty-emphasis tags: fixed 1 ("the whole skill" cut)
- Colon constructions / filler / vague attribution: clean
```

If every category is clean, say so in one line rather than listing all of them.
