# voice-examples.md Schema

The annotated examples bank. Companion to voice-principles.md. This is where texture lives, so it can grow without bloating the principles file. Load it before drafting anything long-form.

---

## What goes in

Twelve to fifteen verbatim passages from the person's own published or sent writing. Each passage gets a short note (one or two sentences) on the move it demonstrates, so the reader learns the *pattern* and not just the words. Group by genre so it covers the range: long-form, short social, professional (LinkedIn), notes, email.

## The format for each entry

```
**[Move name] ([which piece it's from])**
> [The verbatim passage. Respect the writer's own fragments, em dashes, and
> quirks here. This is their real voice. It is exempt from any anti-slop pass.]

Pattern: [One or two sentences. What move this is and why it works. Name the
transferable thing, so it teaches beyond this single example.]
```

## Selection rules

- Verbatim only. Never paraphrase a passage and present it as theirs.
- Pick passages that each show a *distinct* move (an opener, a close, a metaphor, a self-deprecating aside, a rhythm shift). Redundant examples waste the bank.
- Favor the moves hardest to describe in the abstract. Openings, closings, and rhythm are worth an example. A simple word preference is not.
- Keep passages short. A whole essay bloats the bank. Pull the two to six lines that carry the move, and point to the full piece for deep texture.
- Cover every genre the person writes in, so short-form drafts get short-form examples.

## Keep it sharp, not just long

Cap the bank at 12 to 15 of the strongest. When a new piece nails a move, add it with a one-line note and retire a weaker entry. A bank that only grows becomes a pile. A curated one stays useful.

## A worked entry (as a model)

```
**Inventory tally as the opener (year-in-review essay)**
> 20 conversations. 8 videos posted. 4 apps I built and never used. 0 dollars
> made. 365 mornings without an alarm.

Pattern: front-load a counted list that dramatizes scope before any thesis. The
unflattering numbers ("0 dollars made") undercut the highlight-reel version and
buy trust.
```

Use that shape. Real passage, then the pattern named so it generalizes.
